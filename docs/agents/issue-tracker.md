# Issue tracker: GitHub

Issues and PRDs for this repository live in GitHub Issues for `Daky/openmmo-client`. Use the `gh` CLI for issue operations and infer the repository from the configured Git remote.

## Conventions

- Create an issue with `gh issue create`.
- Read an issue and its discussion with `gh issue view <number> --comments`.
- List and filter work with `gh issue list`, including labels and comments when relevant.
- Comment, label, close, and reopen work with the corresponding `gh issue` commands.
- When a skill says to publish to the issue tracker, create a GitHub issue.
- When a skill says to fetch a relevant ticket, read the GitHub issue and its comments.

## Pull requests as a triage surface

PRs as a request surface: no.

GitHub pull requests are implementation and review artifacts, not feature requests for the engineering-skills workflow.
